# Vartika Mathur — Insurance Business Analysis Website

A lightweight static website for GitHub Pages.

## Files
- `index.html` — the complete website
- `.nojekyll` — GitHub Pages helper

## Publish on GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.
5. Open the published URL shown in GitHub Pages.

The site uses no external libraries or image assets. The contact links open email or LinkedIn.
